# Contributing

The most useful contribution is a disagreement with evidence.

- **A test vector you classify differently.** Open an issue with the transaction hash, the class you assign, and the receipt log that decides it.
- **A figure you reproduce differently.** State your source, window and method. If the difference is ours, we correct it publicly with a date.
- **A proposed rule change.** Explain what it changes in the published figures. A change to a published definition is a new id ending `.v2`; the old one stays served for at least 90 days.

Please do not include private keys, API keys or personal data in issues or pull requests.
